# 🌐 Personal Portfolio Website

## 📌 Overview

This project is a responsive multi-page personal portfolio website designed to showcase my academic journey, skills, and projects. It provides an organized and interactive way to present information about my education, interests, and future goals as a Computer Science student.

---

## 🎯 Features

* 🏠 Multi-page website (Home, Higher Education, Previous Education, Summary, etc.)
* 📱 Fully responsive design for mobile and desktop devices
* 🎨 Styled using modern CSS (Flexbox, Grid, animations)
* 🖱️ Interactive elements (hover effects, clickable cards, navigation)
* 🎥 Embedded media (images and video content)
* 📊 Structured data using tables and lists

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Design (Media Queries)

---

## 📂 Project Structure

* `index.html` – Home page
* `higher_education.html` – Information about higher education options
* `previous_education.html` – Educational background
* `Conceptx.html` – High school experience
* `Kaplan.html` – Current studies and modules
* `summary.html` – Summary of HTML & CSS concepts used
* CSS files for styling and layout

---

## 🚀 What I Learned

* How to structure a multi-page website using HTML
* How to design responsive layouts using Flexbox and CSS Grid
* How to create interactive UI elements using CSS animations and hover effects
* How to organize content clearly using tables, lists, and sections
* How to maintain consistent design across multiple pages
